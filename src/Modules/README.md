# Diyarak Modules

This directory contains business modules built on top of Platform Foundation and Platform Core.

Current Diyarak Market 1.0 structure:

- `Diyarak.Market.Property` — property module with an initial domain baseline for aggregate identity and supported top-level property categories.
- `Diyarak.Market.Company` — company module foundation.

Additional Property behavior, Company domain models, APIs, and dependencies are added only when supported by concrete requirements.
