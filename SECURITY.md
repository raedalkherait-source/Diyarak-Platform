# Security Policy

Report suspected vulnerabilities privately to `security@diyarak.app`. Do not create a public issue containing exploit details, credentials, personal data, or unpublished vulnerabilities.

Include affected component, reproducible steps, impact, and suggested mitigation. The team should acknowledge reports within three business days and communicate remediation status according to severity.

This file is an operational template and must be aligned with the final legal entity, incident response plan, and production support channels before launch.
