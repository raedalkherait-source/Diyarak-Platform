# ADR-0024: Reject ambiguous Market Listing ownership backfills

**Status:** Accepted

## Decision

The Market Listing persistence schema will store `PublisherUserId` in a required PostgreSQL `uuid` column named `publisher_user_id`.

The schema migration will not assign `Guid.Empty`, a random identifier, a shared system user, or any other invented owner to existing Listings.

Before adding the required column, the migration must verify that `market.listings` contains no rows. If any row exists, the migration must stop with a clear error before changing the table.

An environment containing existing Listings requires a separately reviewed data-migration plan based on an authoritative ownership mapping before this schema migration can be applied. Non-production data may instead be removed only through an explicitly approved operational action.

The new column has no database default. Newly persisted Listings receive their non-empty `PublisherUserId` from the domain model through the explicit Integration mapper.

Authentication implementation, ownership transfer, administrative overrides, and the authoritative source for any future legacy ownership mapping remain separate decisions.
