# ADR-0017: Treat Property availability as existence until a Property lifecycle exists

**Status:** Accepted

## Decision

For the current Diyarak Market implementation, a Property is considered available for Listing publication when the referenced Property exists.

`Diyarak.Market.Property` does not currently define lifecycle states such as active, inactive, archived, or deleted.

Publication orchestration must therefore verify Property existence before publishing a Property Listing, without inventing additional Property-state rules.

If a Property lifecycle is introduced later, the definition of publication availability must be revisited explicitly.

This decision does not define the application contract, repository query, resolver implementation, or cross-module communication mechanism used to perform the existence check.
