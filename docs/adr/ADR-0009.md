# ADR-0009: Require explicit approval for Module-to-Core dependencies

**Status:** Accepted

## Decision

Business modules may reference Foundation according to the documented dependency rules.

A business module may reference a Platform Core project only when an accepted architecture decision explicitly approves that dependency and identifies the reusable Core capability or contract being consumed.

The absence of an explicit approval means that a Module-to-Core dependency is not approved.

No Platform Core dependency is approved for business modules by this decision.

In particular, this decision does not approve a dependency on `Diyarak.Platform.Listing` and does not define the deferred sector-agnostic subject-reference contract.
