# ADR-0013: Start Market Listings as drafts before publication

**Status:** Accepted

## Decision

A new `Diyarak.Market.Listing.Listing` starts in a `Draft` state.

A Draft Listing exists before publication and may later transition explicitly to `Published`.

This decision approves only the initial lifecycle states `Draft` and `Published` and the transition from `Draft` to `Published`.

No additional lifecycle state or transition is approved by this decision.

Publication-readiness requirements, required fields before publication, editing behavior in each state, unpublishing, archiving, deletion, and republishing remain separate decisions.
