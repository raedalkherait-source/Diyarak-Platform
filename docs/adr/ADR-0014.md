# ADR-0014: Require core Listing data before publication

**Status:** Accepted

## Decision

A `Diyarak.Market.Listing.Listing` may exist as a `Draft` before all publication data is complete.

Publishing a Listing requires the following core data:

- a valid immutable `ListingSubjectReference`;
- a `ListingContext`;
- a `ListingHeadline`;
- a `ListingPrice`.

`ListingAvailableFromDate` is optional and is not required for publication.

`Publish()` must reject a Draft Listing that is missing any required publication data.

This decision does not define additional publication-readiness requirements, transaction-specific required fields, media requirements, descriptions, publisher requirements, or subject-existence validation.
