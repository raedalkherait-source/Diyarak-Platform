# ADR-0018: Introduce an Application layer for cross-module orchestration

**Status:** Accepted

## Decision

Cross-module use-case orchestration belongs to a dedicated Application layer.

Application projects may coordinate business modules without moving domain rules into Hosts or Integrations.

The dependency direction is:

- Application may reference Foundation, approved Platform Core contracts, and business Modules needed by a use case.
- Application must not reference Hosts.
- Application must not depend on concrete Integrations.
- Modules remain isolated from other Modules and do not depend on Application.
- Hosts compose Application use cases and concrete Integration adapters.
- Integrations may implement ports required by Application use cases.

The initial use case for this layer is publishing a Market Listing after verifying that its referenced Property exists.

The exact persistence adapter and Property lookup implementation remain separate decisions.
