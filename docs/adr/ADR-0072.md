# ADR-0072: Agency Packages and Listing Quotas

| Status   | Accepted                   |
|----------|----------------------------|
| Date     | 2026-11-21                 |
| Context  | Phase 3 — Monetization     |

## Context

The platform needs to control how many listings each user can have concurrently
active (Published or Paused). Individual users receive a default free quota.
Agencies can purchase packages that raise their quota for a limited period.

## Decision

### Domain model

`AgencyPackage` is an aggregate root in `Diyarak.Market.Company`:
- `ListingQuota` — maximum concurrent active listings.
- `ExpiresAt` — when the package stops being effective.
- `IsRevoked` / `RevokedAt` — moderators can revoke early.

### Quota enforcement

`PublishListingUseCase` resolves the effective quota before publishing:
1. If the user owns an agency with an active package, use its `ListingQuota`.
2. Otherwise, use `AgencyPackage.DefaultFreeQuota` (5).
3. Count listings with status Published or Paused via `IActiveListingCounter`.
4. If count >= quota, return `QuotaExceeded`.

The check runs inside the transaction to avoid TOCTOU races.

### Persistence

- `market.agency_packages` table with check constraints on quota > 0 and
  expiry > creation.
- Composite index on `(agency_id, expires_at)` for the active-package query.
- `IActiveListingCounter` implemented as a `COUNT(*)` query filtered by status.

### API

- `GET /api/market/quota` — user's effective quota, active count, remaining.
- `POST /api/moderation/agencies/{id}/packages` — assign a package (moderator).
- `DELETE /api/moderation/agencies/{id}/packages/{pkgId}` — revoke (moderator).
- `GET /api/moderation/agencies/{id}/packages` — list packages (moderator).

### Portal

The dashboard shows a quota bar with active count, total quota, and package
info. Admin can assign packages via the moderation panel.

## Consequences

- Every publish checks the quota; a cold-path COUNT query is acceptable.
- When an agency's package expires, they fall back to the free quota; existing
  published listings above the quota remain visible but no new ones can be
  published.
- Moderators control monetization manually for now; self-service purchase can
  be added later by integrating with the payment system.
