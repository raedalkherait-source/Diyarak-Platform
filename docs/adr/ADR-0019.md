# ADR-0019: Use an Application port for Property existence checks

**Status:** Accepted

## Decision

The Market Listing publication use case will depend on an Application-owned `IPropertyExistenceChecker` port.

The port accepts a Property `Guid` identifier and asynchronously reports whether that Property exists.

`Diyarak.Market.Application` will use this port before publishing a Property Listing.

The Application layer does not reference `Diyarak.Market.Property` directly for this check.

A concrete Integration adapter may implement the port using persistence or another approved data-access mechanism.

The port represents existence only. It does not introduce Property lifecycle states or additional publication-availability rules.

Persistence implementation, transaction boundaries, and Listing loading or saving remain separate decisions.
