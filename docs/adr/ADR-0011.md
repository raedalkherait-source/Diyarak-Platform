# ADR-0011: Keep a Listing subject reference immutable

**Status:** Accepted

## Decision

A `Diyarak.Market.Listing.Listing` is created for one published subject.

Its `ListingSubjectReference` is immutable for the lifetime of that Listing.

Changing the published subject requires creating a new Listing rather than replacing the subject reference on an existing Listing.

This decision preserves Listing identity around one published subject and avoids reusing the same Listing record for a different asset.

Subject existence validation, subject availability behavior, and Listing lifecycle states remain separate decisions.
