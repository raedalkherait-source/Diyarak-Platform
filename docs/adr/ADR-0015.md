# ADR-0015: Restrict core Listing edits to Draft state

**Status:** Accepted

## Decision

The core publication data of a `Diyarak.Market.Listing.Listing` may be assigned or changed only while the Listing is in the `Draft` state.

The core publication data covered by this decision is:

- `ListingContext`;
- `ListingHeadline`;
- `ListingPrice`;
- `ListingAvailableFromDate`.

After a Listing reaches `Published`, changes to these values are rejected.

This decision does not define an editing workflow for published Listings, an unpublish transition, a revision model, or republishing behavior.
