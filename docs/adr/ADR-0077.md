# ADR-0077: Contractors Directory

## Status

Accepted

## Context

Property buyers and owners in Syria frequently need construction, renovation and maintenance
services. A directory of contractors on the same platform helps them find local service providers
without leaving the site.

## Decision

- Add a `Contractor` aggregate to `Diyarak.Market.Company` with fields: name, description,
  governorate, district, specialty (enum: GeneralConstruction, InteriorDesign, Plumbing,
  Electrical, Painting, Tiling, Carpentry, Landscaping, Demolition, Surveying), phone.
- Each user can create at most one contractor profile (unique owner constraint).
- Profiles start unpublished; the owner publishes/unpublishes them. Only unpublished profiles
  can be deleted.
- API: authenticated CRUD at `/api/market/contractor`, public list at
  `/api/market/public/contractors` (filterable by governorate and specialty, paginated).
- Portal: public `/contractors` page with governorate and specialty filter chips;
  management at `/my/contractor`.
- A "مقاولون" link in the main navigation header.

## Consequences

- Users can list their contractor services alongside the real-estate marketplace.
- The public can browse by governorate and specialty, with direct phone contact.
- Future iterations can add ratings, reviews, and verification badges.
