# ADR-0073: CSV Bulk Import for Agency Listings

## Status

Accepted

## Context

Agencies managing many properties need a way to create listings in bulk rather than one at a time
through the portal form. A CSV-based import is the simplest approach that works across all platforms.

## Decision

- A new `POST /api/market/import/csv` endpoint accepts a CSV file (max 2 MB, max 200 rows).
- Only authenticated users who own an agency can use bulk import.
- Each valid CSV row creates a `Property` and a draft `Listing` (not published).
- The CSV parser validates required headers: category, city, headline, publishingRole, transactionIntent.
- Optional columns: governorate, district, price, currency, isOnRequest, allowCalls, allowWhatsApp.
- Invalid rows are skipped and reported in the response; valid rows are still created.
- The response returns `{ created, failed, errors[] }`.
- The portal provides an upload page at `/my/import` with format documentation.

## Consequences

- Agencies can onboard their inventory quickly without manual data entry.
- Draft status ensures the publisher reviews and publishes each listing individually.
- The 200-row limit prevents excessive database writes in a single request.
- Quota enforcement happens at publish time, not at import time, so imports are not blocked by quota.
