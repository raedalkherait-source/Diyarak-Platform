# ADR-0074: Progressive Web App (PWA)

## Status

Accepted

## Context

Most Diyarak users access the portal from mobile devices on slower connections. A PWA allows
the portal to be installed on the home screen and provides an offline fallback page.

## Decision

- Add a web app manifest (`/manifest.json`) with app name, theme color, icons and `display: standalone`.
- Add a service worker (`/sw.js`) with a network-first strategy for navigation requests and an
  offline fallback page at `/offline`.
- Generate 192px and 512px PNG icons from an SVG source; include the SVG as a scalable icon.
- Register the service worker from a client component (`ServiceWorkerRegistration`).
- Set `apple-touch-icon` and Apple Web App metadata for iOS home-screen installs.
- The service worker caches only the offline page; all other resources use standard Next.js caching.

## Consequences

- Users can install Diyarak on their home screen on Android and iOS.
- Navigation requests that fail (offline) show a friendly Arabic fallback page.
- The service worker is minimal (network-first, no precaching) to avoid stale-content issues.
- Future iterations can add precaching of search pages and listing photos.
