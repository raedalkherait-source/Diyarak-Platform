# ADR-0012: Validate Listing subject types in the consuming business module

**Status:** Accepted

## Decision

`Diyarak.Platform.Listing` remains sector-agnostic and validates only the structural requirements of `ListingSubjectReference`.

The business module consuming the reference is responsible for deciding which subject types it supports.

`Diyarak.Market.Listing` currently supports only the `market.property` subject type.

A Market Listing must reject a subject reference whose subject type is not one of the explicitly supported Market subject types.

This validation does not verify that the referenced Property exists. Subject existence validation and resolution remain separate decisions.
