# Platform Core Tests

This directory contains tests for implemented Platform Core capabilities.

Current coverage:

- `Diyarak.Platform.Identity.Tests` — tests for the Identity domain baseline.
- `Diyarak.Platform.Listing.Tests` — tests for `ListingSubjectReference` assignment, equality, and blank subject-type rejection.

Platform Core scaffold projects do not have empty test projects. Tests are added when concrete behavior is implemented.
